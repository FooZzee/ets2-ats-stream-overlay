## [1.2.2] - 2026-11-17

> [!IMPORTANT]
> **Релиз v1.2.2** обеспечивает полный переход на единую десктопную архитектуру Cockpit HUD, устраняет сбои завершения и отмены рейсов на автобусах и грузовиках, обновляет кинематику и дизайн карточек уведомлений, добавляет автоуведомление об обновлениях в предпросмотре OBS с ЭЛТ-анимацией и Web Audio эффектами, а также полностью перерабатывает графический установщик и терминал Pip-Boy 3000 на нативный WPF.

### 🚀 Добавлено
* **🔔 Автоуведомление об обновлении в предпросмотре OBS (`assets/js/ets2-telemetry.js`, `assets/css/ets2-base.css`):**
  * Автономный опрос GitHub API с защитой от rate-лимитов (`HTTP 403`) через кэширование в `localStorage` (интервал 3 часа).
  * Аутентичный ретро-стиль зелёного люминофора Pip-Boy 3000 (`#22c55e`, `#15803d`, глубокий фон `#070b09`, сканлайны кинескопа).
  * Анимации включения и выключения ЭЛТ-монитора (`crtPowerOn` и `crtPowerOff`) с развёрткой луча из горизонтальной линии.
  * Побуквенная печать текста со скоростью 22 мс на символ, мигающим зелёным курсором `▌` и контейнером с фиксированной высотой (без скачков оверлея).
  * Синтез звуков через Web Audio API: щелчок тумблера питания, свист строчного трансформатора ТДКС (15.6 кГц), размагничивание и реалистичные щелчки клавиатуры терминала.
  * Интерактивные команды тестирования в консоли: `window.testTelemetryEvent('update')` и `window.testTelemetryEvent('update', 'v1.2.3')`.
* **🛠️ Автономный терминал обновлений Pip-Boy 3000 (`Update-Overlay.bat` и `scripts/updater.ps1`):**
  * Графический интерфейс на базе WPF, работающий строго в STA-потоке (`Single-Threaded Apartment`) с принудительной поддержкой TLS 1.2.
  * Защита от сбоев сети с 5-секундным таймаутом и информативным выводом сообщения при исчерпании лимитов GitHub API без падения приложения.
  * Двуязычная локализация (`RU` / `EN`) с мгновенным переключением и встроенным просмотром списка изменений.
* **🚚 Редизайн графического мастера установки (`Install-Overlay.bat` и `scripts/installer.ps1`):**
  * Полная переработка интерфейса на WPF в фирменном стиле ETS2 / ATS Cockpit HUD (`#0d1117`, `#151b24`, `#2a3444`, золотой янтарь `#f59e0b`, циан `#38bdf8`).
  * Унифицированные шаблоны кнопок со скруглением `CornerRadius="8"`, сменой градиента при наведении и тактильным сдвигом при клике.
  * Бесшумный запуск и работа: полное удаление синтезатора 8-битного звука и звуковых сигналов.
  * Усиленное автоопределение библиотек Steam (реестр `HKCU`/`HKLM`, `libraryfolders.vdf`, сканирование дисков и манифестов `appmanifest_227300.acf` для ETS2 и `appmanifest_270880.acf` для ATS).
  * Папка установки оверлея по умолчанию `C:\OverlayOBS_FooZzee` с кнопкой «Обзор...».
  * Опция создания ярлыка проверки обновлений (Pip-Boy 3000) на Рабочем столе (`ETS2-ATS Overlay Update.lnk`).
  * Встроенные модальные окна документации («Список изменений» и «Список команд») в тёмном стиле без вызова Блокнота.
  * Компактная разметка окна (`Width="740"`, `SizeToContent="Height"`, `ResizeMode="CanMinimize"` без полос прокрутки).
  * Фирменные блоки «Поставить звезду на GitHub» и «Поддержать проект» с точными векторными иконками.
  * Отображение актуальной версии пакета `v1.2.2` в заголовке, бейдже шапки и статусной строке футера.
* **🎯 Векторные знаки ограничения скорости (30–130 км/ч):**
  * Полный набор векторных знаков скорости с шагом 10 км/ч (30, 40, 50, 60, 70, 80, 90, 100, 110, 120, 130) с контрастной красной каймой и чётким шрифтом.
* **😊 Динамические векторные эмодзи комфорта пассажиров (`busSat`):**
  * Добавлены контрастные векторные SVG-эмодзи уровней удовлетворённости пассажиров с уведомлениями об изменении настроения (`bus_comfort_up` / `bus_comfort_down`).

### 🔄 Изменено
* **🖥️ Единая десктопная архитектура Cockpit HUD:**
  * Полностью удалён файл `ets2-vertical.html` и неиспользуемый код вертикального режима; проект полностью сфокусирован на флагманской десктопной сцене 16:9 (`1920×1080` — `ets2-desktop.html`).
* **🎨 Редизайн карточек уведомлений и кинематика:**
  * Увеличен масштаб карточек уведомлений на +10% для идеальной читаемости на трансляциях высокой чёткости.
  * Новая кинематика: плавный выезд сверху вниз в зону лобового стекла и неподвижное растворение на месте (без уезда назад).
  * Единый тёмный корпус Cockpit HUD (`#0e131b`) с плотной подложкой и контурными световыми индикаторами статуса.

### 🐛 Исправлено
* **🛑 Завершение и отмена рейсов (`plugin.cpp`, `ets2-telemetry.js`):**
  * Добавлен нативный перехват всех вариантов событий SCS SDK (`job.delivered`, `job.cancelled`, `bus_job.*`, `car_job.*`).
  * Заблокировано ложное уведомление «-100% комфорта», возникавшее при сбросе значения `busSat` игрой в 0 при завершении рейса.
  * Реализован надёжный fallback по изменению состояния контракта в телеметрии при отсутствии явного события от игрового движка.

## [1.2.0] - 2026-11-16

> [!IMPORTANT]
> **Релиз v1.2.0** добавляет всплывающие игровые уведомления о событиях телеметрии в верхней зоне лобового стекла (14% сверху, уровень ~150px), 100% локализацию бейджей карточек без англицизмов, полный словарь редких штрафов SCS SDK, процедурный синтезатор звуков Web Audio API, сквозную статистику сессии стрима и интерактивные команды Twitch-чата (`!гудок`, `!рация`, `!рейс`, `!стата`, `!тягач`, `!водитель`, `!ставка`).

### 🚀 Добавлено

#### 🔔 Всплывающие уведомления в верхней части экрана (`.telemetry-event-toast`)
* **Размещение в зоне лобового стекла:**
  * Позиционирование в верхней зоне лобового стекла (`top: 14%; left: 50%`) с плотным непрозрачным фоном (`#0e131b`), акцентными рамками, показом 4.5 с и последовательной FIFO-очередью.
  * 100% чистота русской локализации: полностью русские бейджи (`ШТРАФ`, `ОПЛАТА`, `АЗС`, `ПАРОМ`, `ПОЕЗД`, `КОНТРАКТ`, `ОТМЕНА`, `ГРУЗ`, `СТО`, `РЕЗЕРВ`, `АВТОБУС`, `КОМФОРТ`, `СИГНАЛ`, `РАЦИЯ`, `СТАТИСТИКА`, `ПОБЕДИТЕЛИ`).

#### ⚡ Захват игровых событий в плагине (`overlayobs_foozzee_telemetry.dll`)
* **Перехват игровых событий SCS SDK в реальном времени:**
  * Фиксация событий `player.fine.offence` (штрафы за нарушения ПДД), `player.tollgate.paid` (оплата проезда по платным дорогам), `player.use.ferry` (паромная переправа), `player.use.train` (ж/д переправа), `job.delivered` (доставка груза) и `job.cancelled` (отмена рейса).
  * Полный словарь редких штрафов SCS SDK: `illegal_trailer` (неразрешённый прицеп), `damaged_vehicle` (критическая неисправность ТС), `illegal_border_crossing` (нарушение госграницы), `hard_shoulder_violation` (движение по обочине) и `generic` с уникальными векторными SVG-иконками и звуками.

#### 🛠️ Телеметрические детекторы автопарка
* **Урон груза и тягача:**
  * Отслеживание скачка урона груза (`>= 1%`) или удара тягача (`>= 3%`), красный тост с треснувшим ящиком и глухим ударом + тревожным писком компьютера.
* **Техобслуживание на СТО:**
  * Автоматическое обнаружение ремонта на стоянке при сбросе износа до 0%, изумрудный тост с ключом и звуком пневмогайковёрта.
* **Резерв топлива:**
  * Одиночное предупреждение за заправку при остатке топлива ниже 12%, янтарный тост с колонкой и предупреждающим сигналом Scania/Volvo.
* **Рейсы пассажирских туров DLC Coaches:**
  * Фиксация остановок (`bus_stop`) со звуком пневмодверей и колокольчиком, а также предупреждение о дискомфорте пассажиров (`bus_comfort`).

#### 📊 Статистика сессии стрима и расширенная карточка сдачи рейса
* **Сквозной учёт поездок стрима:**
  * Сквозной учёт завершённых контрактов, пройденных километров, рекорда скорости, заработка, штрафов и индекса безопасности вождения.
  * Расширенная карточка сдачи груза (удержание 7.0 с) с отображением маршрута, километров, дохода, опыта, штрафов за поездку и победителей зрительских ставок.

#### 💬 Интерактивные команды Twitch-чата (`ets2-chat.js`)
* **Интерактив со зрителями с ролевым доступом:**
  * `!гудок` / `!фафа` / `!honk`: доступ для VIP, подписчиков, модераторов и стримера, ролевой кулдаун, басовитый пневмогудок тягача.
  * `!рация <текст>` / `!сиби <текст>` / `!cb <текст>`: доступ для фолловеров, фильтрация ссылок, лимит 70 символов, карточка 15 канала со звуком squelch и Roger Beep.
  * Инфо-карточки: `!рейс`, `!стата`, `!тягач`, `!водитель`.
  * Тотализатор рейса: тихий приём ставок `!ставка чистый` / `!ставка штраф` с выводом победителей при сдаче груза.

#### 🧪 Тестовые инструменты и демо-режим

## [1.1.2] - 2026-11-15

> [!IMPORTANT]
> **Релиз v1.1.2** добавляет встроенную автономную систему проверки обновлений с GitHub в стилистике терминала Pip-Boy 3000 (Fallout) с синтезом звуков CRT и печатной машинки, полную 100% двуязычную адаптацию (RU/EN), встроенную базу городов и остановок ETS2/ATS, кнопку поддержки автора в графическом установщике и обновлённые инструкции интеграции в OBS Studio.

### 🚀 Добавлено (Added)

#### 📟 Автономный терминал обновлений в стиле Pip-Boy 3000
* **Автоматическое обнаружение релизов:** Модуль (`assets/js/ets2-updater.js`) обращается к GitHub API (`releases/latest`), сравнивает семантические версии и предупреждает о появлении нового обновления без блокировки основного стрима.
* **Аутентичный ретро-дизайн кинескопа (CRT):** Зелёный люминофорный интерфейс (`#00ff66`), горизонтальные скан-линии (scanlines), виньетирование стеклянной колбы монитора и анимация включения / схлопывания луча CRT.
* **Встроенный WebAudio ретро-синтезатор:** Процедурная генерация звука щелчков клавиш механической печатной машинки при выводе текста и высоковольтного спадающего звука выключения кинескопа.
* **Интерактивные кнопки управления:**
  * **`[ 🚀 ОБНОВИТЬ ]`** — моментально открывает страницу нового релиза на GitHub в браузере по умолчанию.
  * **`[ 💤 ДА НУ ЕГО НАФИГ ]`** — красиво выключает терминал, сохраняя отклоненную версию в хранилище сессии, чтобы не отвлекать стримера во время рейса.
* **Умный двуязычный парсинг описания релиза:** Модуль автоматически распознаёт и извлекает из тела релиза GitHub описание на языке пользователя (русском или английском), аккуратно очищая Markdown-разметку.
* **Интерактивное ускорение:** Клик в любую область текста терминала мгновенно завершает посимвольную печать («Skip Typewriter»).
