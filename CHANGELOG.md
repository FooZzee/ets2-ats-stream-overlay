# Changelog / История изменений

All notable changes to the **ETS2 / ATS Cockpit Telemetry Stream Overlay** will be documented in this file.
Все значимые изменения в проекте документируются в данном файле.

---

## [1.1.0] - 2026-11-15

### Added / Добавлено
- **Поддержка Euro Truck Simulator 2 — DLC Coaches (Пассажирские рейсы):**
  - Полная поддержка автобусных рейсов из нового **DLC Coaches** с сохранением 100% совместимости с грузоперевозками в ETS2 и ATS.
  - Извлечение маршрута «Откуда → Куда» (например, «Йёкюльсаурлоун → Рейкьявик») через нативные атрибуты остановок SCS SDK (`source_stop.*` и `destination_stop.*`).
  - Отображение текущего уровня удовлетворённости пассажиров в бегущей строке бортового компьютера: **`КОМФОРТ: XX%`** (`RU`) / **`SATISFACTION: XX%`** (`EN`).
  - Флаг `isBusJob` и распознавание типа рейса в мосте телеметрии и веб-оверлее.
- **Новые каналы телеметрии SCS SDK в C++ плагине (`scs_direct_telemetry.dll`):**
  - `bus_job.average_satisfaction` (`FLOAT`) — средний комфорт и удовлетворённость пассажиров автобуса.
  - `rest.stop` (`S32`) — таймер времени до обязательного отдыха/сна водителя в минутах.
  - `truck.electric.enabled` (`BOOL`) — статус бортовой электросети/зажигания тягача/автобуса.
  - `truck.engine.enabled` (`BOOL`) — статус работы двигателя.
- **Интеграция DonationAlerts в графический установщик (`Install-Overlay.bat`):**
  - Добавлено поле ввода секретного токена DonationAlerts в установщик `scripts/installer.ps1`.
  - Поле маскировано звёздочками с кнопкой переключения **Показать / Скрыть** (**Show / Hide**).
  - Автоматическая запись введённого токена в `channels.donationAlerts.socketToken` файла `config.js`.

### Changed / Изменено
- **100% непрозрачность нижней панели («торпеды»):**
  - Фон нижней приборной панели в `ets2-desktop.html` (`assets/css/ets2-desktop.css`) сделан **полностью непрозрачным (`alpha = 1`, 100% solid)**. Это предотвращает просвечивание ярких текстур асфальта и разметки под спидометром, приборами и маршрутом в OBS Studio. Рамка веб-камеры, чат и алерты сохраняют прозрачность.
- **Очистка от Kick (Twitch-Only):**
  - Удалены все упоминания и ссылки на Kick.com из оверлеев `ets2-desktop.html`, `ets2-vertical.html`, скриптов и шаблонов конфигурации.
  - Блок соцсетей в правом нижнем углу аккуратно выровнен под единый канал Twitch.
- **C++ плагин `scs_direct_telemetry.dll`:**
  - Пересобрана 64-битная Release DLL (размер: 210,432 байт, SHA256: `6E9B18395E41C99A46FA9643301805F1D340D64A9069250CC6CFEBB038728DF9`) с улучшенной обработкой событий конфигурации `bus_job` и регистрацией 4 новых каналов.

## [1.0.0] - 2026-11-12

### Initial Release / Первый релиз
- **Нативный C++ плагин SCS Telemetry SDK 1.16:**
  - Прямое чтение телеметрии через Shared Memory (`Local\FooZzeeSCSTelemetry`) без сторонних программ-посредников.
- **Двухрядная приборная панель Desktop (`1920×1080`):**
  - Спидометр, круиз-контроль, КПП, тахометр, педали газ/тормоз/руль, полный блок индикаторов и ламп приборной панели.
  - 7 датчиков бортового компьютера, бегущая строка экономики, шкала прогресса маршрута и навигация.
- **Вертикальная сцена Mobile (`1080×1920`):**
  - Адаптация под безопасные зоны TikTok Live, YouTube Shorts, Reels.
- **Расчёт реального времени в пути (`real-eta-panel`):**
  - Конвертация игрового времени с учётом масштабов карт `1:19`, `1:3`, `1:10` в реальные часы и минуты.
- **Чат Twitch IRC и FIFO-очередь оповещений:**
  - Интеграция с чатом Twitch, последовательные всплывающие алерты с поддержкой DonationAlerts.
- **Графический 1-клик установщик (`Install-Overlay.bat`):**
  - Двуязычный визард с автоматическим поиском установленных ETS2 / ATS в Steam.
